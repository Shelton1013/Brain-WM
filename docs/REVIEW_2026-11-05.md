# Paper and code review, 2026-11-05

Scope: current SpecBraM target/training code, frozen-probe evaluation, dataset alignment,
cohort uncertainty, manuscript theory and numerical claims, and reproducible repository
entry points. This is a local technical review, not independent replication or peer review.

## Checks and fixes

- The classical FFT target, one-sided Parseval normalization, 3/3/4/13/12 frequency-bin
  counts, patch-locality, five-dimensional masked MSE and saved checkpoint configurations
  agree. CPU checks cover known sinusoid power and phase, a NumPy reference, locality,
  configuration round-trip, forward/backward and feature shape.
- All 42 selected model/dataset BA, kappa and weighted-F1 point estimates agree with saved
  predictions. An isolated regeneration reproduced all 28 generator-produced TeX tables
  again after the uncertainty and manuscript updates, with no mismatches.
- Unknown ISRUC labels previously shifted subsequent epochs. The loader now preserves
  their position and skips the matching signal epoch, with a cache-version change. All
  100 original expert-1 scoring files were checked: only recognized 0/1/2/3/5 codes occur,
  so existing ISRUC metrics are unaffected.
- Bootstrap input now explicitly selects the sleep mode and rejects duplicate identities;
  avg3 and center10 can no longer silently overwrite each other. Existing source predictions
  contained only avg3.
- Majority-label stratification could hold a singleton sleep subject fixed in every draw.
  Mixed-label tasks now use ordinary subject bootstrap, conditioned on class coverage;
  homogeneous binary subject diagnoses retain label stratification. The 1,000-resample
  intervals were recomputed from existing predictions; all point estimates are unchanged.
- TUAB has three patients shared by train/validation in the reference per-class split.
  Its test patients are disjoint from both. The preparation code preserves the reported
  protocol, warns about validation overlap, and rejects any test-patient overlap. The paper
  discloses this limitation rather than calling that validation partition subject-disjoint.
- The checkpoint usage example now restores all saved model arguments, including tokenizer
  and target, instead of reconstructing the legacy filterbank architecture.
- Required probe/plot dependencies and explicit current-model settings are documented.
  Core baseline/task paths can be changed through environment variables.

## Scientific interpretation

The revised manuscript limits sufficiency to the stated spectral model, distinguishes
marginal phase ancillarity from context predictability, separates independent-patch and
correlated Gaussian prediction, and retains posterior uncertainty in conditional variance.
The zero-floor log-power identities are distinguished from the implemented positive floor.
Achieved R² and an SGD upper bound do not establish Bayes predictability or a causal speedup;
the observed step/representation comparisons remain empirical evidence. Clustering fits no
supervised classifier, but REVE readout selection uses validation labels. Low-label fractions
refer to training epochs, with validation-based hyperparameters reused.

## Remaining limits

TUAB/TUEV overlap TUEG pretraining; all external models were not re-pretrained on matched
data or compute. Small test cohorts and selected checkpoints limit statistical conclusions.
The paper files are drafts, with anonymous/placeholder submission metadata. Checkpoint
weights are not included in Git, and the historical dated workbooks are not refreshed by
this review. The original training forward pass evaluates dormant auxiliary branches even
when their weights are zero, so step efficiency is not a measured wall-clock speedup.

No training was restarted and no existing server processes or files were modified.
