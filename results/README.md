# Result provenance

These are saved experiment aggregates, not a new run of the models. Current tables are
generated by `paper/arxiv/make_arxiv_tables.py` from `arxiv_data/` and `bootstrap/boot.json`.

The current main family is linear-tokenizer, patch-local classical-band FFT power,
`log(P + 1e-3)`, no JEPA/SIGReg loss, 2,388 hours, 2,100 patients, pretraining seeds 42/43/44.
The generator's `MAIN='m'` and `FAM`/`TFAM` mappings identify the exact saved result keys.
Earlier narrow-band Hann/log1p/+SIGReg results are retained for provenance; they are not
interchangeable with the current main family.

- `bootstrap/boot.json`: single-checkpoint point estimates, cohort-bootstrap uncertainty,
  three-seed summaries and paired differences. On 2026-11-05 uncertainty was recomputed
  from the same predictions using ordinary subject resampling for mixed-label tasks and
  label-stratified resampling for homogeneous binary subjects. No point estimate changed.
- `arxiv_data/eval_results/`: probes, ablations, clustering, target R² and other aggregates.
- `arxiv_data/model/`: fine-tuning metric JSONs, not training weights.
- Dated `.xlsx` workbooks: historical snapshots. The latest date does not guarantee coverage
  of all later experiments or the revised bootstrap intervals; use the JSONs/current tables.

The main comparison reports one checkpoint per model and cohort confidence intervals.
Target ablations report three pretraining seeds and their standard deviation. These two
uncertainties must not be substituted for one another. Paired intervals are nominal and
unadjusted for multiple comparisons, not equivalence or noninferiority tests.

Raw recordings, checkpoint binaries and per-sample prediction/feature arrays are excluded
from Git. Predictions can be regenerated with `--pred_dir`. TUAB's original per-class
train/validation partition shares three patients; its test patients remain disjoint.
TUAB/TUEV were not excluded from TUEG pretraining.
